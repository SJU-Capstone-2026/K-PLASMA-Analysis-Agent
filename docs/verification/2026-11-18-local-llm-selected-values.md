# LocalLLM v2.5.2: 근거 선택형 설명 작성과 오류 복구

v2.5.1(`c061314`) 이후의 재계획 피드백 연결과 이 문서의 근거 선택 변경을 v2.5.2로 묶는다. 재계획 입력 수정의 배경과 첫 검증은 [재계획 입력·지시서 정합성](2026-11-18-local-llm-replan-feedback.md)을 참조한다. 런타임 모델·설정이나 공개 graphVersion 이름을 바꾸는 버전이 아니다.

Qwen이 숫자 참조 표식과 긴 근거 ID를 직접 작성하던 부분을 요청별 선택지로 바꿨다. 숫자 값은 V선택지, fact_ids와 evidence_ids는 E선택지로 제한하고, 코드는 기존 참조 문법과 실제 근거 ID 목록으로 변환한다. 기존 DataAnswerDraft·숫자 검증·d1 답변 검토·그래프·최종 응답 경로는 유지한다. 최종 로컬 검사779개가 통과했고, Q02 설명 요청에 참조 오류를 한 번 주입한 최종 웹1회는 재계획1회·답변 재작성1회를 거쳐 COMPLETE·통과150.53초였다. d1 계획 검토6/6 match와 답변 검토 within_evidence를 확인했다.

아래 기록은 단계별 결과를 구분한다. 최초 조회 전용 웹은68.91초였으나 설명 작성은 호출하지 않았다. 숫자 참조만 코드로 옮긴 중간 버전은 재작성의 긴 근거 ID 복사 오류로 PARTIAL·실패147.76초였다. 최종 보완은 그 복사 경로까지 E선택지로 제한한 결과이며, 각 웹 실행의 작업량이 달라 전체 시간 차이를 단순 개선율로 계산하지 않는다.

## 배경과 변경

기존 설명 작성은 자유 문장 안에 근거 ID와 항목명을 가진 참조 표식을 Qwen이 직접 넣었다. 이전 Q02에서는 항목명 자리에 실제 숫자를 써서, 정확한 조회 후에도 설명 검증과 재작성에 실패했다.

현재 내부 작성 응답은 다음 방식을 사용한다.

- 코드는 이번 근거의 실제 사용 가능한 값 항목마다 V1·V2 등의 선택지를 만든다.
- Qwen의 설명 본문·한계 문장은 `segments`로, 가정은 문장별 `segments` 배열로 작성한다. 일반 문장 조각과 근거 선택 조각을 구분한다.
- 근거 조각의 `ref`는 이번 선택지로 제한한 JSON 스키마를 사용한다. 선택지가 없으면 근거 조각 자체가 스키마에 없다.
- 코드는 선택지의 실제 근거 ID·항목명으로 참조 표식을 생성하고, 필요한 `evidence_ids`를 중복 없이 추가한다. 기존 DataAnswerDraft의 `text`·문자열 assumptions로 변환한 뒤 기존 검증과 렌더링을 적용한다.
- 제공되지 않은 선택지, 숫자를 넣은 ref, 모델이 직접 쓴 참조 문자열은 거부한다. 여러 일반 문장 조각으로 나눠 작성한 참조 문자열도 거부한다.
- 중간 응답도 같은 선택지를 코드가 해석해 기존 공개 블록 이름으로 보낸다. 내부 선택지·참조 표식이 화면에 나오지 않도록 한다.

일반 개념 설명 경로는 기존 GeneralAnswerDraft를 유지한다. 실제 데이터 설명도 최종 DataAnswerDraft·그래프·숫자 근거 검증·d1 검토·재계획/재작성 상한은 유지한다. 앞서 반영한 재계획 피드백 수정도 유지했다. 기존 v2/v3나 UI 코드는 수정하지 않았다.

이번 웹 검증은 수정 후 기존 조회 흐름과 최종 응답의 호환성을 확인한다. 새 설명 작성 경로는 인공 입력·전송 스키마·중간/최종 응답 로컬 검사로 확인했으며 실제 Qwen의 새 설명 생성은 미검증이다. 실제 설명 질문이나 다른 문항을 자동 추가하지 않았다. 적절한 근거 선택과 해석의 정확성, 불필요한 설명 단계 추가 및 d1의 작업 범위 오판은 이 변경으로 해결됐다고 주장하지 않는다.

## 후속 웹1회: 실제 설명 작성과 고의 참조 오류 복구

사용자는 결과 의미 설명 요청과 고의 오류 주입을 모두 승인했다. 원본 Q02의 조건은 유지하면서 실제 수치를 인용한 의미 설명을 추가한 비공개 변형 질문을 새 대화에 한 번 제출했다. 공식40문항과 원본 데이터는 수정하지 않았다. 앞 절과 같은 Docker VM1536MiB·Qwen·d1·그래프·최종 응답 계약을 사용했다. 실행 전 준비 프로필과 실제 그래프의 `plan_review_enabled=true`를 확인했고, 관측한 실행 상태에서도 true였다.

임시 평가 장치는 실제 Qwen의 스트림 응답과 실제 `SelectedValues.compile` 결과를 기록했다. 정상 컴파일 결과를 확보한 뒤 설명 본문에 있는 참조 한 개의 값 항목만 존재하지 않는 항목으로 바꿨다. 질문·실제 값·DB는 바꾸지 않았다. 이 손상은 Qwen이 만든 자연 오류가 아니라 사용자가 승인한 시험용 오류다. 기존 답변 조립·검증과 최대1회 재작성을 그대로 거쳤으며, 재작성 결과에는 다시 오류를 주입하지 않았다.

Qwen이 선택한 짧은 ref를 코드가 실제 값 참조로 바꾸는 부분은 두 작성 호출에서 정상 작동했다. 하지만 `fact_ids`와 모델이 명시하는 `evidence_ids`는 여전히 긴 ID를 복사하는 형식이다. 재작성에서는 제공된 근거 ID의 끝부분을 다른 값으로 바꿨고, 자동으로 추가한 정상 인용이 있어도 잘못된 ID를 함께 가진 답변은 기존 검증에서 거부됐다. 따라서 이 변경으로 모든 근거 ID 복사 오류까지 없앴다고 주장할 수 없다. 이번 요청에서는 제품 코드를 추가 수정하지 않았다.

| 엔진 내부 측정 | 시간 |
|---|---:|
| Qwen 최초 계획 입력 처리+생성 | 55.08초 |
| d1 계획 검토 서비스 처리 | 8.93초 |
| Qwen 최초 설명 입력 처리+생성 | 36.80초 |
| Qwen 재작성 입력 처리+생성 | 39.62초 |

엔진 내부 시간은 전체 응답 시간과 기준이 다르며 연결·모델 전환·DB·그래프 처리 등을 모두 포함하지 않는다. 앞 절의 조회 전용 실행과 작업량이 달라 개선율로 비교하지 않는다.

관측 resident 피크18.230GiB, 메모리 경고0·critical0·추가 swap0이었다. 워커 연결 준비4요청과 실제 평가4요청(Qwen계획1·d1계획검토1·Qwen설명1·Qwen재작성1)을 구분한다. d1 API1요청 안에서 검사항목6개는 기존 MLX Q8 단일 방식으로 각각 처리했다. 별도 정상 대조 웹 실행이나 추가 모델 평가는 하지 않았다.

관측·채점은 비공개 `observe.py`·`grade.py`로 수행했다. 저장한 실제 응답의 재조립과 스트림/선택/컴파일 결과 일치 검사는 추가 모델 호출 없이 수행했다. 기존 소스51개·설정 프로필·런타임 정보·Docker 제한,150 Run·버전·과거 대화 해시 보존 및 새 웹 요청1건을 확인했다. 평가 후 입력 기록·컴파일 기록·오류 주입 기능을 모두 해제했고, 로컬 워커와 웹·모델 서버는 계속 실행 중이다. 원시 입력·응답·판정·화면은 Git 제외 `.local/runtime/v2.5.1-selected-values-q02-explain-fault/`에 비공개 보관한다. 제품 코드 변경이 없으므로 소프트웨어 검사 전체를 다시 실행하지 않았으며, 설명의 과학적 정확성은 이번 결과로 검증되지 않았다.

## 최종 보완: fact_ids와 evidence_ids도 E선택지로 제한

앞선 실패는 숫자 참조 생성이 정상이어도 fact_ids와 모델이 명시하는 evidence_ids에는 긴 ID를 직접 복사할 수 있는 경로가 남아 있었기 때문이다. 사용자가 이 두 목록도 짧은 선택지만 고르도록 수정하고, 같은 설명 요청·고의 참조 오류를 웹에서 다시 검증하도록 승인했다.

### 최종 구현

- 기존 SelectedValues에 요청별 E선택지 카탈로그를 추가했다. 숫자 참조의 V선택지는 유지한다.
- 내부 작성 응답의 fact_ids와 해석·한계의 evidence_ids는 이번 E선택지만 허용하는 enum 배열이다. 미등록 번호·실제 긴 ID·잘못 복사한 ID는 허용하지 않는다.
- 숫자가 없는 관찰 근거도 E선택지로 고를 수 있다. 근거가 전혀 없으면 두 목록은 빈 배열만 허용한다.
- 코드는 선택된 E번호를 실제 긴 ID로 변환하고, V선택지에 연결된 인용도 중복 없이 추가한 뒤 기존 DataAnswerDraft를 반환한다.
- 작성 지침과 실제 입력에 E선택지 카탈로그를 연결했다. 반려 답변에 기존 긴 ID가 있더라도 재작성 출력은 이번 E선택지만 사용하도록 명시하고 스키마로 제한한다.
- 그래프·기존 조립/근거 검증·d1 지침/선택지·최종 계약·워커 설정·런타임 매니페스트는 변경하지 않았다. 의도적 복제 차이 문서와 계약 보존 검사만 이 내부 형식 변경에 맞춰 갱신했다.
