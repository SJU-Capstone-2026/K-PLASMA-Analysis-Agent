# Agent v2 3회차 평가 기록

평가일: 2026-11-11 KST. 소스는 `eff226944dd0e01e201d81556173d105e7b4c4b9`로 고정했다.
PR #33 통합 코드 `51d077c9878b635c96da709eb7eb2aefd36699e1`에서 새로 실행한 유료 평가가 아니다.
이 기록은 기존 로컬 보고서·최종 집계·Decisions 요약을 대조한 내부 평가 요약이며 원시 실험 파일은 포함하지 않는다.

## 최종 성적

| 평가 | 자동 정답 검사 | 답변 내용 검토 포함 최종 통과 | 최종 통과율 |
| --- | ---: | ---: | ---: |
| 웹 Agent | 40/40 | **39/40** | **97.5%** |
| API Agent | 38/40 | **37/40** | **92.5%** |
| Agent 전체 | 78/80 | **76/80** | **95.0%** |
| Decisions 단독 | 80/80 | 고정 계획 정답과 대조 | **100%** |

자동 검사에 더해 주 에이전트가 응답과 고정 정답의 질문 이행·수치·단위·근거를 대조했다.
웹 1건과 API 1건을 내용 실패로 낮췄다. 인간 전문가 검수나 별도 유료 심사 모델은 사용하지 않았다.
화면 자동 검사는 웹 40/40이었으며 웹 답변 정확도 39/40과 다른 지표다.

## 방법과 조건

- Agent는 동결된 같은 40문항·Run 149개의 불변 버전·독립 정답을 실제 웹과 backend API에서 각각 1회 실행했다.
  웹/API는 독립 모델 실행이므로 계획과 응답이 서로 같다고 가정하지 않았다.
- 웹은 실제 입력·버튼·HITL·화면을 확인했고 API는 실제 요청 접수·대기·선택·재개·저장을 사용했다.
- Decisions 단독은 정상 40회·오류 40회였다. 서로 다른 28계획(14쌍) 중 기존 13쌍을 3번씩,
  마지막 1쌍을 1번씩 실행한 80호출이다. Agent 전체 평가와 별도다.
- 계획·답변·Decisions 모델은 모두 `gpt-6-luna`; 계획·재계획·답변 추론은 `low`였다.
  Decisions API에는 reasoning effort 지정 항목이 없었다.
- 계획 Decisions ON을 설정·체크포인트로 확인했고 Agent 80요청 전체에 실제 계획 검토 기록이 있었다.
- 모델 timeout은 호출별 90초, 요청 전체 재계획 최대 2회·답변 재작성 최대 1회였다.
- 도구는 `forward_lookup`, `reverse_search`, `compare_runs`, `explain_answer`이며 `derive`·`await_input`을 유지했다.
  RAG는 포함하지 않았다. 실패 문항의 추가 유료 실행은 없었다.

준비물·현재 실행 명령·산출물 판정 방법은 [v2 평가 실행 안내](../development/agent-v2-evaluations.md)에 있다.
향후 규칙 기반/RAG 비교는 [v3 실험 방법 초안](../development/agent-v3-evaluation-method-draft.md)과 별개로 구분한다.

## 최초 통과와 복구

| 지표 | 웹 | API | 합계 |
| --- | ---: | ---: | ---: |
| 최초 계획·코드 검증 후 첫 계획 Decisions PASS | 36 | 36 | 72 |
| 재계획·재작성 없이 최종 통과 | 34 | 32 | 66 |
| 계획 Decisions 지적 후 재계획해서 최종 통과 | 1 | 1 | 2 |
| 그 외 재계획 후 최종 통과 | 3 | 2 | 5 |
| 답변 재작성 호출 | 1 | 2 | 3 |
| 최종 실패 | 1 | 3 | 4 |

행들은 서로 다른 단계의 지표이므로 모두 더하지 않는다. 계획 검토 PASS는 최종 답변 통과가 아니다.
재계획은 8개 질문에서 10호출이었고 7개 질문이 최종 통과했다. 답변 재작성은 3개 질문에서 1회씩이었다.
계획 Decisions가 지적한 2건은 모두 재계획 후 최종 통과했다. 최종 통과에 복구 후 통과를 포함하되 최초 통과로 합치지 않았다.
출력 한도 종료는 2개 웹 질문에서 총 3회 발생했고 두 질문 모두 기존 재계획 예산 안에서 복구했다.

## 남은 실패

| 경로 | 건수 | 원인 요약 |
| --- | ---: | --- |
| 웹 | 1 | 극값 자체와 두 극값의 차이를 답변 문장에서 혼동 |
| API | 1 | 전체 후보 비교에 불필요한 정확 후보 개수 제약을 넣어 예정에 없는 추가 질문 발생 |
