# LocalLLM v2.2 — 로컬 체크포인트 복원

2026-11-18. v2.1 커밋 `7803b297423b9f6002cf3031c7647a9ae13368a3`에서 분기해 v2.3 시작 전 백업의 v2.2 파일을 복원했다. v2.2 실제 웹 비교 때 동결한 로컬 그래프 Python 파일 41개의 SHA-256이 전부 일치한다. 기존 v2.3 커밋 `1a24bf35a66eaf207c23cf1b9520d14abf03ca5d`에는 당시처럼 v2.2와 v2.3 작업이 함께 들어 있다. 이 체크포인트는 별도 로컬 브랜치에 이후 복원한 기록이다.

`required_prior_outputs` 명칭·지침과 과거 `requires` 읽기 호환, Qwen 계획 디스크 KV 캐시, 개발 메모리 정책이 이 버전의 범위다. d1은 기존 llama.cpp Q8 개별 검토이며, Docker VM 2 GiB와 d1 검토 활성화는 당시 웹 평가 환경이다. Qwen 캐시는 기본 OFF다.

당시 앞 5문항의 웹 자동 검사와 UI 검사는 OFF/ON 각각 5/5였다. 평균 전체 시간은 96.992→68.250초, Qwen 입력 처리는 32.153→0.478초였고, 동일 지시서에서 10,217토큰을 재사용했다. [필드 변경](2026-11-14-local-llm-v2.2-prior-outputs.md), [캐시 구현](2026-11-14-local-llm-v2.2-qwen-plan-cache.md), [OFF/ON 평가](2026-11-14-local-llm-development-memory.md) 참고.

복원본에서 `python -m pytest -q -c pytest-v2-local-llm.ini`는 466개 통과, 초기 복제 전용 8개 제외였다. Ruff, `git diff --check`, `node scripts/verify-public-files.mjs`도 통과했다. 웹 수치는 당시 측정 기록을 사용했다.
