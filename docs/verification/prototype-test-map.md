# v12.3.1 기준 테스트 대응표

외부 `tests/`의 실제 `test(...)` 이름 102개를 파일과 순서로 식별한다. 97개는 `scripts/reference/compare-tests.mjs`가 원본 callback/assertion에 **새 ESM fallback 모듈**을 공급해 실행한다. 원본 expected 값은 외부에만 보존하며 `buildForwardViewModel`에 명시적인 Run 인자만 공급한다. 구조 검사 5개는 실제 React DOM·키보드·로컬 요청·후속 질의 assertion으로 대체한다. `npm run verify:reference`가 두 빈 PostgreSQL에서 실제 폴더/ZIP 150 Run을 등록하고 이를 연결한다.

2026-10-03 보관된 외부 gate의 ESM 97개와 구조 01/03/04/05 증거를 유지한다. 독립 리뷰에서 구조 02의 memory container 의미가 미검증임을 확인했고, 수정 후 별도 실제 HTTP/PostgreSQL 인공 memory 결과 테스트에서 PASS했다. 따라서 현재 102개 coverage는 보관된 외부 실행과 이 신규 검증의 합계이며, 수정된 전체 `verify:reference`를 다시 실행했다고 주장하지 않는다. 각 ID의 새 assertion은 아래에 연결한다. 최종 browser에는 실제 DB의 기록 흐름·네 폭 SVG 비교도 포함한다. 이것은 원본-source-only 102개 baseline과 다르다. backend·frontend 전체 통과 또는 D1 데모 호환성 통과를 뜻하지 않는다. 기준 없는 명시적 reference 명령은 실패하며 일반 CI만 외부 항목을 명시적으로 skip한다. [수용 검증](acceptance.md)의 유예·잔여 차이도 함께 읽는다.
