# 실제 평가에 사용한 질문 원문 12개

질문 문장은 원문 그대로다. 첨부·선택 정보는 질문 텍스트와 별도로 제출한 입력이다.
기록 관련 05~12번은 모두 Run을 사전 첨부했다. 정답·실험 결과 수치는 이 문서에 포함하지 않는다.
JSON 원본: [evaluation-questions.json](evaluation-questions.json). 평가 조건·한계는 [자료 안내](README.md)를 참조한다.

## v3-frozen-01

- 범주: `forward`
- 사전 첨부: 없음
