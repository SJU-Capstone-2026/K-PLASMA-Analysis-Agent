# 의사결정 Agent 시연 구현

현재 분석 UI의 스타일을 사용하는 전용 탭을 추가한다. 기존 V2 그래프를 이용해 실제 Run을 검색한다. 전용 대화는 서버에서 v2로 고정하고 분석 대화 목록과 구분한다. 시연의 후보 선택은 공용 의사결정 기록에 추가하지 않는다.

1. 기존 대화방 생성 경로에 시연방 구분을 추가한다. 기존 방과 신규 분석방은 이전 생성·활성화 계약을 따른다. 시연방의 버전 변경 요청은 기존 버전 정책으로 반려한다.
2. 등록된 정확한 Run ID 또는 정확한 공정 조건으로 기준을 찾는다. 기준 Run을 선택할 수 있게 하고 일치하지 않는 참조는 되묻는다. 기준 지표에서 목표 범위를 계산하고 사용자 승인 후 V2에 명시적인 검색 조건을 보낸다.
3. 저장된 V2 결과의 조건과 Run 버전을 확인한다. 같은 압력과 소스에서 다른 바이어스로 측정한 일치 후보를 표시한다. 기준과 후보의 측정값, 비교의 한계, 사용자가 선택한 Run을 표시한다.
4. 시연방 분리와 버전 고정, 대표·대체 Run, 빈 결과·결측, 조건 불일치, 선택 동작을 인공 데이터로 검사한다. UI는 390, 800, 1008, 1440px에서 확인한다.
